# Crime Seriousness and Sentence Severity

This repository stores the code and data necessary to reproduce the Sentencing Academy 'Response to Independent Sentencing Review Call for Evidence' (www.sentencingacademy.org.uk/.co.uk)

The datasets included in this repository were manually derived from two criminal justice statistics reports from the Ministry of Justice. From 2010 to 2024 we used data from 'Criminal Justice Statistics quarterly: June 2024' (www.gov.uk/government/statistics/criminal-justice-system-statistics-quarterly-june-2024), and from 2004 to 2009 we used data from 'Criminal justice statistics quarterly: December 2014' (www.gov.uk/government/statistics/criminal-justice-system-statistics-quarterly-december-2014).

For further details see the technical report (also available in this repository as .pdf file), where we explain the analytical procedures followed to obtain the plot trends in sentence severity and crime seriousness reported in our response to the independent sentencing review.
